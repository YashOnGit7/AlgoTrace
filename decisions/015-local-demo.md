# 015: Runs locally for the demo

## Context (plain words)
Public hosting is optional, while the four-week target is a presentation version.

## Options considered
- Run the demo locally.
- Host a public service.

## Decision
Run locally for the demo; public hosting is outside the initial phase.

## Why (beginner level)
Local setup avoids adding deployment work before the core flow is ready.

## Trade-offs
The presenter must install the required tools and start local services.

## Interview answer (30 seconds)
The demo runs on the presenter's computer. That keeps the initial delivery focused on the canvas, compiler, browser engine, and results instead of hosting infrastructure.
